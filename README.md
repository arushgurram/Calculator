# Modern Calculator App

A sleek, desktop GUI calculator built with Python using **CustomTkinter**. It features a dark-themed user interface, clear typography, and essential mathematical operations.

---

## Features

* **Custom Dark Theme:** Modern UI styled with custom color palettes and Consolas/Segoe UI typography.


* **Standard Arithmetic:** Supports addition, subtraction, multiplication, and division.


* **Extra Operations:** Includes percentage calculations (`%`), sign toggling (`+/-`), and backspace functionality (`←`).


* **Clean Formatting:** Automatically formats trailing zeros for integer results (e.g., `5.0` displays as `5`).


* **Error Handling:** Safe handling for division by zero with clean reset behavior.



---

## Requirements

* Python 3.x
* `customtkinter`
* `tkinter` (Standard Python library)

---

## Installation & Setup

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

```


2. **Install dependencies:**
```bash
pip install customtkinter

```


3. **Required Assets:**
Ensure the following asset files are present in your project directory:


* `calculator-ico.ico`

* `calculator.png`



4. **Run the Application:**
```bash
python main.py

```
